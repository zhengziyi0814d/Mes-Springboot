# MES 常见问题问答（AI 客服知识库）

> **用途**：本文档用于上传到扣子（Coze）知识库，是 AI 客服回答问题的核心依据。
> **格式约定**：`Q` 为用户可能的提问方式，`A` 为标准答案。编写新条目时请保持"一问一答成对"，答案写清菜单路径与按钮名称。
> **维护约定**：系统功能变更（如新增菜单、调整流程）时，同步更新本文档并重新上传知识库。
> **注意**：以下菜单名称基于当前 MES 系统结构整理，如与实际界面有出入，请以系统实际菜单为准并修正本文档。

## 一、名词解释类

**Q：MES 是什么？**

A：MES（Manufacturing Execution System，制造执行系统）是连接计划层与车间现场的管理系统，用于管理生产过程的各个环节。本系统包含系统管理、基础数据、工艺管理、订单工单、物料需求计划、数据大屏、数字孪生等模块。

**Q：BOM 是什么？**

A：BOM（Bill of Materials，物料清单）是产品的零件组成清单，记录了产品由哪些零部件构成、每个零部件的用量。在 MES 系统中通过「工艺管理 → BOM 管理」菜单维护，可以新增、编辑 BOM 及其零部件明细。

**Q：工艺路线是什么？**

A：工艺路线是产品从原材料到成品的加工顺序，由一系列工序按先后顺序组成。在 MES 系统中通过「工艺管理 → 工艺路线」菜单维护，定义产品的加工流程。

**Q：工序是什么？**

A：工序是生产过程中一个相对独立的加工环节，例如"车削""装配""检验"。工序是组成工艺路线的基本单位，在 MES 系统中通过「工艺管理 → 工序管理」菜单维护，工序下还可维护工序内容（操作说明）、物料清单等附属信息。

**Q：工单是什么？**

A：工单是下达给车间的生产任务单，记录了生产的产品、数量、计划时间等信息。在 MES 系统中通过「订单管理」菜单创建和跟踪。

**Q：物料需求计划是什么？**

A：物料需求计划是根据生产任务推算出的原材料和零部件的需求安排，明确"需要什么物料、需要多少、什么时候需要"。在 MES 系统中通过「计划管理 → 物料需求计划」菜单填报和管理。

**Q：在制品是什么？**

A：在制品（WIP，Work In Process）指已经投入生产、但尚未完成全部加工过程的产品或零部件，即"正在生产线上加工中的东西"。

**Q：数字孪生是什么？**

A：数字孪生是把真实的生产线和生产过程在电脑中用 3D 模型 1:1 还原，并映射实时数据，方便直观查看生产状态。本系统通过「数字孪生」菜单进入 3D 展示页面。

## 二、登录与账号类

**Q：忘记密码怎么办？**

A：请联系系统管理员在「系统管理 → 用户管理」中重置密码。普通用户无法自行重置密码。

**Q：验证码看不清或不显示怎么办？**

A：点击验证码图片即可刷新更换一张；如果完全不显示，请检查网络是否正常、浏览器是否禁用了 Cookie，刷新页面后重试；仍无法解决请联系系统管理员。

**Q：登录后提示权限不足或看不到某些菜单怎么办？**

A：菜单和功能权限由角色控制，请联系系统管理员在「系统管理 → 角色管理」中确认您的角色，并在「系统管理 → 权限管理」中为您的账号分配正确的角色。

**Q：如何修改个人头像和个人信息？**

A：登录后点击页面右上角的头像进入个人设置，可以上传头像（支持 png、jpg 等常见图片格式）和修改基本资料，保存后重新登录或刷新页面生效。

**Q：新同事如何开通系统账号？**

A：由系统管理员在「系统管理 → 用户管理」中点击「新增」，填写用户名、姓名、初始密码等信息并分配角色，创建完成后新同事即可用该账号登录。

## 三、功能操作类

**Q：如何新增零部件？**

A：依次点击「工艺管理 → 零部件管理」，进入零部件列表页面，点击左上角「新增」按钮，填写零部件编号（可留空由系统自动生成）、名称、规格等信息，点击保存即可。

**Q：如何新增 BOM 并添加零部件明细？**

A：第一步，进入「工艺管理 → BOM 管理」，点击「新增」，填写 BOM 名称、所属产品等信息并保存；第二步，在 BOM 列表中找到该记录，进入明细维护页面，添加组成产品的零部件及用量，保存即可。

**Q：如何创建工艺路线并关联工序？**

A：第一步，先在「工艺管理 → 工序管理」中确认所需工序已建立；第二步，进入「工艺管理 → 工艺路线」，点击「新增」填写路线信息；第三步，进入路线详情，按加工顺序添加各道工序并保存。

**Q：如何查看某个产品的完整工艺信息？**

A：使用「工艺管理 → 工艺查询」功能，选择要查询的产品或零部件，系统会汇总展示对应的 BOM 构成、工艺路线及各工序内容，无需在多个菜单间来回切换。

**Q：如何创建并下发工单？**

A：进入「订单管理」，点击「新增」创建工单，填写生产产品、数量、计划开始和完成时间等信息并保存；确认信息无误后将工单下发，车间即可按工单组织生产。下发后如需修改，请按公司流程处理。

**Q：如何填报物料需求计划？**

A：进入「计划管理 → 物料需求计划」，点击「新增」，选择所需物料、填写需求数量、需求时间等信息，保存并提交即可。可通过列表页查看已填报计划的审批与执行情况。

**Q：列表页数据太多，怎么快速找到目标记录？**

A：每个列表页面顶部都有搜索区域，支持按编号、名称等条件模糊查询；输入关键字后点击「查询」按钮即可过滤，配合底部分页栏翻页查看。查询完后可点击「重置」恢复全部数据。

**Q：上传附件有什么大小和格式限制？**

A：单个附件大小不能超过 10MB，支持常见图片（png、jpg）、Word 文档（docx）、PDF 等格式。超过限制的文件请压缩后再上传，或联系管理员协助。

**Q：数据大屏在哪里看？**

A：通过「数字化平台 / 数据大屏」相关菜单进入，页面以图表方式集中展示生产计划、产量等关键指标，适合车间现场展示和例会汇报。

**Q：系统支持 3D 展示吗？**

A：支持。通过「数字孪生」菜单可进入 3D 数字孪生页面，用三维模型直观展示生产线布局与运行状态，页面内可用鼠标旋转、缩放视角。

## 四、报错与异常类

**Q：操作时页面提示 401 或自动跳回登录页怎么办？**

A：这是登录状态已过期的表现（系统默认约 30 分钟无操作自动退出）。重新登录即可；如果登录后马上又跳回登录页，请清理浏览器 Cookie 后重试，仍异常请联系管理员。

**Q：点击保存没有反应或提示服务器异常怎么办？**

A：第一步，检查表单中的必填项是否全部填写、格式是否正确（如日期、数字）；第二步，按 F5 刷新页面后重试；第三步，如果反复出现，请截图并记录操作步骤，联系系统管理员排查（管理员可查看服务端日志定位原因）。

**Q：提示"验证码错误"怎么办？**

A：验证码区分大小写且有时效限制，超时或输错后需点击验证码图片刷新，输入最新显示的验证码再登录。

**Q：提示"网络错误"或页面加载不出来怎么办？**

A：先确认自己的网络是否正常（能否打开其他网页）；再确认系统是否正在维护或重启（可询问管理员）；如果只有本机异常，尝试更换浏览器（推荐 Chrome 或 Edge）或清理浏览器缓存。
